## Executive Summary

Nexford Consulting Group Ltd ("NCG") is pleased to submit this response to Meridian Law Group LLP's Request for Proposal for the design, development and implementation of a Legal Practice Management System ("LPMS").

NCG is a specialist technology consultancy with 14 years of experience delivering software solutions to professional services organisations including law firms, accountancy practices and financial services providers. We have completed three similar LPMS implementations for UK regional and national law firms in the past four years.

We believe our proposal offers Meridian Law Group the best combination of domain expertise, value for money, and proven delivery methodology. Our total proposed engagement cost is £485,000 exclusive of VAT.

---

## 1. Our Understanding of the Requirement

Meridian Law Group requires a fully integrated LPMS capable of supporting:

- Case management across litigation, corporate and property practice areas
- Integrated time recording and billing
- A secure client portal for document sharing
- Regulatory compliance tooling (SRA, AML, GDPR)
- Management reporting and dashboards
- Microsoft 365 integration
- Mobile accessibility for fee earners

We have delivered all of these components across previous LPMS engagements and have pre-built accelerator modules which significantly reduce delivery risk and cost.

---

## 2. Proposed Solution

### 2.1 Platform

We propose to build the LPMS on the Microsoft Power Platform (Power Apps, Power Automate, Dataverse) with a React-based client portal. This approach is fully cloud-native, uses Meridian's existing Microsoft 365 licensing, and eliminates dependency on any third-party LPMS software vendor.

### 2.2 Key Features

| Feature | Our Approach |
|---|---|
| Case management | Custom Power Apps canvas app, configurable by practice area |
| Time recording | Integrated Power Apps module with Outlook plugin |
| Client portal | React SPA with Azure AD B2C authentication |
| Compliance module | Pre-built AML workflow + SRA checklists |
| Reporting | Power BI embedded dashboards |
| Mobile | Progressive web app (PWA) — no separate app store submission |
| Integration | Microsoft Graph API for M365; RESTful API for third-party systems |

## 3. Project Approach and Timeline

### 3.1 Methodology

NCG uses a hybrid Agile-Waterfall delivery methodology, with fixed-scope phases and two-week sprint cycles within each phase. A dedicated Project Manager will provide weekly status reporting.

### 3.2 Proposed Timeline: 18 Months

| Phase | Description | Duration | End Date |
|---|---|---|---|
| Phase 1 | Discovery, requirements and system design | 2 months | June 2024 |
| Phase 2 | Core case management and time recording | 4 months | October 2024 |
| Phase 3 | Integrations, compliance and client portal | 4 months | February 2025 |
| Phase 4 | Reporting, mobile and UAT | 4 months | June 2025 |
| Phase 5 | Go-live, cutover and hypercare support | 4 months | October 2025 |

### 3.3 Risks and Mitigations

| Risk | Likelihood | Mitigation |
|---|---|---|
| Requirements scope creep | Medium | Fixed-scope phases with formal change control |
| Data migration complexity | Medium | Dedicated discovery sprint in Phase 1 |
| Integration delays (third parties) | Low–Medium | Early vendor engagement; API contracts in Phase 1 |
| User adoption | Low | Embedded training programme and champion network |
