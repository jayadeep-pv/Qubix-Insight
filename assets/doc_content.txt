Tenant Onboarding Procedure 14. Troubleshooting 1. Overview Qubix Insight is a multi-tenant SaaS platform that uses Azure AI services to extract, compare, and analyse legal and commercial documents. This guide documents every Azure resource required to run the platform and provides step-by-step provisioning instructions including all required permissions, API access, and configuration values. Platform Components Component Technology Frontend React 19 SPA, Azure Static Web Apps, MSAL authentication Backend Azure Functions (.NET 10 Isolated Process) AI Processing Azure OpenAI (GPT) + Azure AI Document Intelligence (OCR) Storage Azure Blob Storage (multi-tenant containers) Data Store Microsoft Dataverse (Power Platform) — one environment per tenant Identity Microsoft Entra ID (multi-tenant app registration) 2. Each tenant has its own Dataverse environment and Blob Storage container. The backend uses a single Service Principal (app registration) to connect to all Dataverse environments. Blob Storage uses DefaultAzureCredential (Managed Identity) with User Delegation SAS generation. JWT claims (tid) are used to identify tenants at runtime — no custom headers are trusted for tenant resolution. The frontend is a multi-tenant MSAL application using the /common authority in production. 3. Azure Resource Naming Standards All Azure resources for the Qubix Insight platform follow Microsoft's Cloud Adoption Framework (CAF) naming conventions. A consistent naming pattern makes resources immediately identifiable by type, product, environment, and region without opening the portal. 3.1 Naming Pattern The standard pattern is: &lt;type-prefix&gt;-&lt;org&gt;-&lt;app&gt;-&lt;env&gt;-&lt;region&gt;[-&lt;instance&gt;] Pattern Components &lt;type-prefix&gt; Microsoft CAF standard abbreviation for the resource type (see table below) &lt;org&gt; Organisation name: ilogix &lt;app&gt; Product / application name: qubixinsight &lt;env&gt; Environment code: dev | tst | prod &lt;region&gt; Short Azure region code: ukw (UK West) | uks (UK South) | we (West Europe) | eus (East US) &lt;instance&gt; Optional 2-digit sequence number when multiple instances of the same type exist: 01, 02 IMPORTANT: Storage Accounts have strict rules: maximum 24 characters, lowercase alphanumeric only — NO hyphens. All other resources use hyphens as separators. 3.2 Environment &amp; Region Codes Environment Codes dev Development — local/cloud dev environment, used by engineers tst Test / UAT — pre-production testing and user acceptance prod Production — live, customer-facing environment Region Codes ukw UK West — PRIMARY deployed region (UK South quota pending on new subscriptions) uks UK South — target region once quota approved (request 4 vCPUs via Usage + quotas) we West Europe — Netherlands (fallback if UK regions unavailable) ne North Europe — Ireland eus East US — US East Coast eus2 East US 2 — US East Coast (higher OpenAI quota availability) sc Sweden Central — highest Azure OpenAI model availability 3.3 Resource Type Prefixes (CAF) These are the Microsoft-recommended prefixes for every resource type used in this project. Tenant Onboarding Procedure Follow these steps to onboard a new customer tenant to the platform. Step Action Details 1 Create Dataverse Environment admin.powerplatform.microsoft.com → Environments → New. Name: Qubix Insight - &lt;TenantName&gt;. Type: Production. 2 Install Managed Solution Import the Qubix Insight managed solution into the new environment. 3 Add Application User Settings → Application users → New → Add Qubix Insight API service principal (Qubix_ClientId) → Assign role. 4 Create Blob Container Navigate to sailogixqubixidocsprod → Containers → + Container. Name: tenant-&lt;short-name&gt; (lowercase, no spaces). 5 Get Customer AAD Tenant ID Ask the customer for their Azure AD Tenant ID (Directory ID) from portal.azure.com → Entra ID → Overview. 6 Create Tenant Settings Record Open the Master Dataverse → hollis_tenantsetting → New record → fill all columns. 7 Set Subscription Tier hollis_subscriptiontier: Trial (initial) or Standard/Enterprise as contracted. 8 Set isActive = true hollis_isactive must be checked (true) for the tenant to log in. 9 Test Login Ask a user from the tenant to log in at the SWA URL. Confirm they access their Dataverse environment. 10 Verify Blob Access Upload a test document and confirm it appears in the correct Blob container. 11 Upgrade Tier if required Update hollis_subscriptiontier to Standard to unlock Compare and Scoring modes. IMPORTANT: The tenant is identified at runtime solely by the Azure AD Tenant ID (tid claim) in their JWT. If a user logs in from a tenant not registered in hollis_tenantsetting, they will receive a 404 response. Always register the tenant BEFORE announcing the platform to users. 14. Troubleshooting Problem Symptom Resolution Tenant not found or inactive User receives 404 on login. Check hollis_tenantsetting in the Master Dataverse. Verify hollis_aadtenantid matches the user's AAD tenant and hollis_isactive = true. Dataverse connection failed — AADSTS error ServiceClient.IsReady = false. Error contains "AADSTS65001" or "AADSTS700016". The Dynamics CRM user_impersonation permission is missing or admin consent not granted. Go to Entra ID → Qubix Insight API → API permissions → add Dynamics CRM → user_impersonation → grant admin consent. Dataverse connection failed — 401 from Dataverse ServiceClient.IsReady = false. Error contains "Unauthorized". The Dynamics CRM permission is present but the app is not registered as an Application User in the target Dataverse environment. Go to Power Platform Admin Centre → Environment → Application Users → add Qubix Insight API. Function App will not start Functions host fails to initialise. No functions listed in portal. AzureWebJobsStorage is missing or has an invalid connection string. Go to Function App → Environment variables → verify AzureWebJobsStorage is set to a valid storage account connection string (sailogixqubixiproduks → Access keys → Connection string). Unable to determine tenant from Bearer token API returns 401 Unauthorized. The JWT does not contain a tid claim. Ensure MSAL is acquiring tokens scoped to the backend API (api://... scope), not Microsoft Graph. Qubix_BlobBaseUrl missing or wrong format Functions throw exception on document upload. Check Qubix_BlobBaseUrl is set in Environment variables. Format must be https://&lt;account&gt;.blob.core.windows.net — no trailing slash, no container name. SAS generation fails (403) GenerateUserDelegationSasAsync throws. The Function App Managed Identity is missing the Storage Blob Delegator role on sailogixqubixidocsprod. Check IAM role assignments on the storage account. Azure OpenAI quota exceeded AI extraction returns 429 Too Many Requests. Increase the tokens-per-minute quota in Azure OpenAI Studio → Deployments → Manage quota. Document Intelligence 400 error OCR fails for a specific PDF. The PDF may be password-protected, corrupt, or exceed page limits. Check Document Intelligence logs in Azure Monitor. CORS error in browser Frontend gets "Access-Control-Allow-Origin" error. Add the SWA URL to the Functions App CORS allowed origins. Ensure "Enable Access-Control-Allow-Credentials" is checked. Trial tenant accessing Compare mode Backend returns 403 Forbidden. Expected behaviour. Update hollis_subscriptiontier to Standard in the Master Dataverse to unlock full modes. Function App deployment fails — SubscriptionIsOverQuotaForSku Azure portal shows "Current Limit (Total VMs): 0" during Function App creation. New Azure subscriptions may have zero vCPU quota in UK South. Immediate fix: change region to UK West — deployment will succeed. Permanent fix: Azure Portal → Subscriptions → Usage + quotas → filter UK South → request quota increase to 4 vCPUs. Also register all resource providers: Microsoft.Web, Microsoft.Compute, Microsoft.Storage, Microsoft.Insights, Microsoft.OperationalInsights (Subscriptions → Resource providers → Register each).
